# Keshav Gupta — Resume

Personal resume site of **Keshav Gupta** — Senior Full-Stack Engineer & Technical Lead (9+ years, Microsoft stack + AI/GenAI).

🔗 **Live:** https://keshav87.github.io/keshav.gupta.github.io/

## Contents
- `index.html` — the resume (single self-contained page; responsive + print/PDF friendly)
- `resume.pdf` / `resume.docx` — downloadable PDF and editable Word versions
- `versions/` — alternate versions (standard, with academics, complete), each as HTML + PDF + DOCX + LaTeX

## Update the resume
Edit `index.html`, then:

```bash
git add index.html
git commit -m "Update resume"
git push
```

GitHub Pages redeploys automatically within ~1 minute.

## Save as PDF
Open the site, click **Download / Print PDF** (or press `Ctrl/Cmd + P`) → **Save as PDF** (A4, default margins).
